# 交给 Codex 的安装提示词

把下面整段发给目标电脑上的 Codex；需要它具备本地文件、执行命令和访问 GitHub 的能力。

```text
请从 https://github.com/yangwei251003/dynamic-skill-router 安装完整动态技能路由器，先读 docs/codex-install.md 并按它执行。安装相同路由核心、完整 MCP 接口、Skill 和全局路由/“深入而不是更大”规则，服务器名保持 dynamic_skill_router；只发现我这台电脑的 Skill、MCP、插件，不复制作者的私人配置或工具库。自动处理可逆安装事项，保留现有设置并备份；不要停在演示模式。完成指南中的本机验收：真实 MCP 版本与全部接口、本机技能全文和哈希、同 routeId 阶段检索、运行时工具建议、简单任务快速路径、私有反馈和全局规则生效。最后报告版本、路径、测试证据、缺口和恢复方法；没验证的不要说已完成。
```

安装完成后的普通任务无需逐次点名路由器。例如直接说“修复这个项目的接口异常并验证”，Codex 按已合并规则先进行一次路由，按实际需要使用本机能力。同一任务的后续阶段复用 `routeId`。

如果当前会话无法刷新 MCP，先完成安装、配置读回和 CLI 验证，明确标为“等待新会话验收”；在新会话继续验证，不能把写好配置称为已加载。
