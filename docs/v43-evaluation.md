## 发布决定

**不整体替换生产版。** 保留集有一类必要候选从旧版通过退化为失败，另有只读约束未保留和图像工具漏召回。整体提升5/100的最终成果证据尚未成立。前五集合外比例改善48.57%，也未达到冻结的50%门槛；全部候选改善60.06%不能用于替换原口径。保留集已消耗，后续修订需要新的独立案例，而非在旧保留集调参后重新称为盲测。

十二领域三组真实成果评测独立记录；无可核验后端版本锁定、认证/软件/设备条件不一致时，不作强因果结论。软件存在、目录可读、当前工具可见、认证通过与任务实际成功是不同状态。

全局质量习惯转换/恢复函数已通过测试，但未把候选片段写入真实全局规则。现用MCP保持旧版；独立候选MCP测试不能冒充当前桌面入口切换成功。一次反馈记录也不构成稳定经验或模型训练。

## 复现与后续

执行 `npm test`、`npm run test:v43`、`npm run demo` 可复现公开回归。私人索引、个人偏好、原始账号工具清单与私有运行日志不公开；本仓库没有声称公开测试可复现私人机器的全部数值。评测方法依据[Agent评测实践](https://www.anthropic.com/research/demystifying-evals-for-ai-agents)，详细方法与来源见[方法资料](../skill/dynamic-skill-router/references/task-methods.md)。

下一次发布应先定位召回退化和约束解析缺口，重新冻结独立保留集，完成覆盖目标领域的真实成果评分及宿主入口验证。确认通过前保持候选分支，不自动覆盖生产文件或用户规则。
