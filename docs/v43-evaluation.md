## 发布决定

**不整体替换生产版。** 保留集有一类必要候选从旧版通过退化为失败，另有只读约束未保留和图像工具漏召回。整体提升5/100的最终成果证据尚未成立。前五集合外比例改善48.57%，也未达到冻结的50%门槛；全部候选改善60.06%不能用于替换原口径。保留集已消耗，后续修订需要新的独立案例，而非在旧保留集调参后重新称为盲测。

十二领域三组真实成果已完成本轮检查：[成果对照与验证边界](v43-artifact-evaluation.md)。旧路由组为7项 PASS、5项 BLOCKED；候选组为8项 PASS、4项 BLOCKED；最小必要路由组为8项 PASS、3项 BLOCKED、1项 NOT_TESTED。这些是已完成范围计数，不是质量总分。盲审27项中20项可评分、7项 BLOCKED，未覆盖的领域不能补分。无可核验后端版本锁定，部分软件连接状态与依赖条件不同，也未完成每组3次独立模型试验或最终成果消融，因此不能作强因果结论。软件存在、目录可读、当前工具可见、认证通过与任务实际成功是不同状态。

## 已独立生效的偏好与方法资料

稳定用户偏好与20张方法参考卡已单独安装，新增常驻规则共326个汉字。规则要求按实际缺口选用方法，允许跳过、参考或改编；详细资料按需读取，个人探索方法仅用于对应请求。这不是把候选排名算法投入生产，也不是模型训练。

当前 Codex 桌面会话已载入新增规则；另一个真实 CLI 进程成功构建输入，并检出新增偏好、方法入口及既有电脑操作和视频偏好。该检查只证明输入加载：两次独立 CLI 模型试运行均在90秒无输出后终止，没有成功的新 CLI 模型任务可供验收。现用 MCP 的健康检查仍返回4.2.0；候选独立 stdio 测试不能冒充实际桌面算法切换成功。一次有依据的维护反馈也不构成稳定经验。

生产代码未替换，因此无需回滚排名算法。新增规则有写前快照、写后读回和局部恢复逻辑；恢复测试保留了并发追加内容。真实恢复只能移除本次拥有的规则段，不能用整份旧快照覆盖后来更新的偏好。已对本次库入口段的纯LF/CRLF变化做等价验证；最新实际文件的只读恢复预演确认段外字节和后续视频资源偏好完整保留。实质修改、异常标记或未经核实的变化须拒绝自动覆盖。方法参考资料可单独保留，不启动后台服务。
